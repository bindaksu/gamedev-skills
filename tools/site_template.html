Game Studio Skill Pack

One skill per seat on a live-service game team, modeled on how top-grossing mobile studios hire. Specialists cover design, narrative, UX/UI, art and audio, growth and money, client and server engineering. Eight meta skills assess, brief, coordinate, manage, review, verify, deliver and serve.

Org patterns that repeat

  • Shared platform, autonomous game teams. Scopely Playgami, Playtika Boost, Playrix LiveOps Platform, King Shared Tech, Tencent Level Infinite.
  • A GM owns the game, not a director chain. Lilith makes each game a subsidiary with 20% team equity.
  • Kill early, soft launch long. Supercell: 30+ kills vs 5 hits. Royal Kingdom: 19 months in soft launch.
  • Reskin proven loops. Kingshot from Whiteout; Royal Match from Toon Blast lineage.

What the postings ask for

  • A/B testing is the most common skill across disciplines.
  • Backend is Java at Supercell and King; Go/Node accepted; infra leans GCP, K8s, Terraform, BigQuery.
  • Native iOS/Android game roles are rare. Native work is C++ with Metal or Vulkan, plus platform SDK layers.
  • AI tooling is now required at Supercell, Playtika and Playrix. King cut ~200 jobs in 2025, including level design, UX and copy.

Orchestration layer

How the meta skills run a feature

The assessment manager scores the game as a numbered edition and ranks top moves. The brief coordinator turns those moves, or any short ask, into a paste-ready agent prompt. The coordinator routes the work to specialists; it then moves through review, verification, delivery and live serving while the producer owns scope and stage gates.

How ambiguous asks were read

Layout design
Level, map and puzzle-board layout in gamedev-level-layout-designer. Screen layout grids live in gamedev-ui-designer.
Campaign design
Story and mission campaigns in gamedev-campaign-designer. LiveOps event campaigns are owned by gamedev-liveops-designer.
Serving expert
Live-service runtime and content serving (SLOs, incidents, CDN hot updates, kill switches) in gamedev-live-serving. The build-and-ship pipeline is gamedev-delivery-release.
Growth vs financial growth
Player retention mechanics in gamedev-growth-designer. UA, LTV, ROAS, payback and P&L in gamedev-financial-growth-strategist.

Using the pack

  • Start broad requests with gamedev-coordinator; score a whole game with gamedev-assessment-manager; turn any ask into an agent prompt with gamedev-brief-coordinator.
  • Skills trigger on their own from the description, or call one by name in Claude Code (/gamedev-pvp-designer) or Codex ($gamedev-pvp-designer).
  • Six companion skills you already have (core-loop-designer, game-economy-balancer, game-playtest-analyst, game-prototype-planner, game-asset-art-director, mobile-game-ux-designer) are linked, never duplicated.
  • Install a subset to keep session prompts lean: ./install.sh --only gamedev-coordinator,gamedev-unity-engineer.
  • Facts that change (store deadlines, SDK versions) are tagged “as of 2026-10; verify”.
  • Remove with ./install.sh --uninstall.
